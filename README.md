## 📱 スマートフォン・現場調査機能

### 1. GPSトラッキング（移動軌跡の自動記録）
- **開始 / 停止**: 画面左下の 🧭 **コンパスボタンを2秒以上長押し** するとトラッキングが開始されます（再度2秒長押しで停止）。
- **ステータス表示**: トラッキング中は、コンパスボタンが深紅の背景と赤い光彩に変化し、右上に赤色点滅の **「REC」バッジ** が表示されます。
- **サンプリング間隔**: **10秒に1回（`10,000ms`）**、高精度モードでGPS位置を取得し、滑らかな軌跡ラインを自動延伸します。
- **並行操作可能**: トラッキング中も地図のスクロール、ズーム、レイヤ操作、作図、計測など、**他のすべての機能を並行して自由に使用** できます。
- **誤操作・離脱防止**: トラッキング中はブラウザの `beforeunload` イベントにより、誤ってリロードしたりページを閉じようとした際に警告ダイアログが表示されます。
- **同日セッションの自動追記**:
  - レイヤリストに **「トラック＋日付」**（例: `トラック20260912`、アイコン: `🚶`）として登録されます。
  - 休憩を挟んで同日中に再度トラッキングを開始した場合、新規レイヤを作らずに **同じレイヤ内に新セグメントとして自動追記** されます。
  - 通常のベクターレイヤと同様に、GeoJSON / KML としてそのままエクスポート可能です。

### 2. オフライン地図モード
- 画面左下の 🌐 ボタンで通常オンラインモードとオフラインモードを切り替えます。
- 事前にキャッシュした地図タイルを IndexedDB に保持し、電波の届かない山奥や現場でも地図を閲覧できます。

## ✏️ ベクター図形編集・作図機能

1. **地図上の図形を2秒長押しで編集モード開始**
   - 地図上のポイント、ライン、ポリゴンを2秒以上長押しすると、上部に編集バナーが展開し編集モードに入ります。
2. **ポイントの移動**
   - ポイント上に表示されるピンク色のパルスハンドルをドラッグすることで、任意の位置へスムーズに移動できます。
3. **頂点の移動・追加・削除**
   - 頂点ハンドルをドラッグして移動、辺の中間ハンドルをドラッグして頂点追加、頂点ハンドルを右クリックで削除できます。
4. **新規図形の追加（「＋ 新規 ▾」）**
   - 編集バナーの「＋ 新規 ▾」メニューから、新しいポイント・ライン・ポリゴンを現在のレイヤに追加作図できます。
5. **選択図形の削除（「🗑️ 削除」）**
   - 図形をクリックして選択し、「🗑️ 削除」ボタン（または <kbd>Delete</kbd> / <kbd>Backspace</kbd> キー）でレイヤから削除できます。
6. **保存とロールバック**
   - **✓ 編集を保存**: レイヤへ編集を確定反映し、レイヤリストを「未保存」ステータスとして管理。
   - **✕ 保存しない**: 編集前の座標・図形状態へ完全に復元（ロールバック）。

## ⚙️ エクスポート & 設定メニュー

- **⚙️ 設定アイコンボタン**:
  - パネル内のエクスポート直下にある円形の「⚙️」ボタンを押すと、設定モーダルが開きます。
  - **エクスポート形式（GeoJSON / KML / PDF / PNG）** をカード形式で選択・切り替え可能（ブラウザに記憶）。
  - 保存済みオフラインキャッシュのタイル数・容量の確認や、ワンクリックでのキャッシュ消去も行えます。
- **💾 統一エクスポートボタン**:
  - 設定された形式のバッジが表示されたエクスポートボタンを押すだけで、確認ダイアログなしで即座に自動ダウンロードされます。
- **レイヤ名のインライン編集**:
  - レイヤーリストのレイヤ名を2秒以上長押しするとインライン編集ボックスが表示され、エクスポート時のファイル名（`[レイヤ名]_[日時].[拡張子]`）としてもそのまま適用されます。
- **レイヤ全範囲ズーム**:
  - レイヤーリストの表示ボタン（`👁`）を2秒以上長押しすると、そのレイヤの境界全範囲へスムーズに自動ズームします。

## 🚀 GitHub Pages への公開手順 (Web公開方法)

本リポジトリの全ファイルをそのまま GitHub のリポジトリにアップロードするだけで、完全な WebGIS アプリケーションとして動作します。

1. **GitHub でリポジトリを作成**:
   - 新しいリポジトリを作成（例: `gis-browser`）。
2. **ファイルをコミット＆プッシュ**:
   - 本フォルダ内のファイル一式を `main` ブランチにコミットしてプッシュします。
3. **GitHub Pages を有効化**:
   - リポジトリの **Settings** → **Pages** を開く。
   - **Source**: `Deploy from a branch` を選択。
   - **Branch**: `main` / `/(root)` を選択して **Save** をクリック。
4. **公開完了**:
   - 数分で `https://<your-username>.github.io/<repository-name>/` で公開され、スマートフォンやPCのブラウザから利用可能になります！

## 🔒 プライバシー & セキュリティ
